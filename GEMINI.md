# D'CrunchyWan POS

## Project

Migration from Google Apps Script POS to Vite.

The legacy AppScript UI is the Golden UI Specification.

## Rules

- Clone the legacy UI.
- Do not redesign.
- Preserve cashier workflow.
- Keep implementation simple.
- Use Vanilla JavaScript.
- Use Vanilla CSS.
- Do not introduce unnecessary abstractions.
- One task = one commit.
- Always run build before finishing.
- Wait for manual browser review before continuing.
